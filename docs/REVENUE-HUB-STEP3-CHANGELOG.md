## Behavioral changes

- KPI cards now render metric-specific `Analyze [metric]` and `How to use [metric]` controls from v2.
- KPI guidance is generated by the UI-only `buildMetricGuidance()` function.
- KPI clicks are handled through one listener on `#kpi-grid` in the normal bubble phase.
- KPI prompt construction now routes through `buildPromptContext()` and model formatting through `formatPrompt()`.
- The existing non-metric prompt content for program, cadence, diagnostic, resource, and role learning is preserved.
- The role prompt path is explicit rather than relying only on fallback behavior.
- The metric prompt is enriched with upstream/downstream evidence, non-skill causes, first-leak investigation, owner/SLA, measurement window, and falsification requirements.
- Former v2 runtime fix styles and the consolidated KPI guidance styles now live in `revenue-performance-v2.css`.
- v4 remains present and v3 still dynamically loads it. No deletion is authorized yet.
